# clinical_demo

Demonstrative repository using publicly available health data for analytic skill building and refreshing


## The goal of this repo is to:
1. import/manage an open-source public health dataset using SQL
2. wrangle the data and conduct the following analyses in R:
- ROC curve
- Risk score development and validation
- Survival analysis (Kaplan-Meier & Cox proportional hazards)
- mixed-effects regression
3. Turn results into a data dashboard using Shiny
